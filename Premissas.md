* Requisitos do Projeto
  * Aplicação: A solução deve conter uma aplicação completa (frontend e backend) que se comunique via API, podendo ser hospedada em um ambiente Windows ou Linux.
  * Contêinerização: O motor da aplicação (por exemplo, NodeJS, Apache2) deve estar em um contêiner Docker.
  * Controle de Versão: É mandatório usar Git e GitHub para gerenciar o código, com um mínimo de 3 branches: Dev, Staging e Master.
  * Automação: Deve-se utilizar GitHub Actions para automatizar o deploy da aplicação em um servidor na AWS.
  * Demonstração: O processo de atualização deve ser demonstrado, mostrando a aplicação antes e depois do deploy.
